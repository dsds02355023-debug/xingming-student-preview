# 姓名學・學生版 Preview

This is an isolated public preview build repository.

- Builds a side-by-side preview APK using `source-student-layout-backfix.zip`.
- Uses Android debug signing only.
- Package ID: `com.xingming.apps.student.preview`.
- Does not publish releases, upload to the production update service, or use production signing secrets.
- APKs are available only as GitHub Actions workflow artifacts.

This repository is public. Its source snapshot and build scripts are publicly visible. Do not add signing keys, credentials, or private production configuration.
